# GigaVibeMiptCode

Это консольный чат с языковой моделью. Запускаешь в терминале, пишешь сообщения, модель отвечает. Никакого интерфейса, только текст.

Работает с любым OpenAI-совместимым API — Ollama, OpenRouter, GigaChat и т.д.

---

## Как запустить

Нужен Python 3.10 или новее.

Сначала установи зависимости:

```bash
pip install -r requirements.txt
```

Потом создай файл `config.yaml` рядом с `main.py` и заполни его (пример ниже). Либо можно задать всё через переменные окружения — тогда файл не нужен.

Запуск:

```bash
cd final_project
python main.py
```

## Настройка

Все параметры можно задать либо в `config.yaml`, либо через env-переменные. Если задано и там и там — env-переменная побеждает.

| Что это              | Env-переменная    | Ключ в config.yaml | Обязательно? |
|----------------------|-------------------|--------------------|--------------|
| URL апи              | `API_HOST`        | `api_host`         | Да           |
| Ключ апи             | `API_KEY`         | `api_key`          | Да           |
| Название модели      | `MODEL`           | `model`            | Да           |
| Макс. сообщений      | `LIMIT_MESSAGES`  | `limit_messages`   | Нет          |
| Макс. символов       | `LIMIT_CHARS`     | `limit_chars`      | Нет          |
| Температура          | `TEMPERATURE`     | `temperature`      | Нет (0.7)    |
| Системный промпт     | `SYSTEM_PROMPT`   | `system_prompt`    | Нет          |

Пример `config.yaml`:

```yaml
api_key: your_api_key_here
api_host: http://localhost:11434/v1/
model: gemma3:270m
limit_messages: 20
limit_chars: 2000
temperature: 0.7
system_prompt: You are a helpful assistant.
```

Пример через env (UNIX):

```bash
export API_KEY=your_api_key_here
export API_HOST=http://localhost:11434/v1/
export MODEL=gemma3:270m
python main.py
```

`config.yaml` добавлен в `.gitignore`, так что ключи в репозиторий не попадут.

## Команды

Пока чат работает, можно вводить специальные команды:

**`\q`** — выйти из программы.

**`/reset`** — сбросить историю переписки и очистить экран. Системный промпт при этом остаётся.

**`@::путь/к/файлу::`** — вставить содержимое файла прямо в сообщение. Можно вставить несколько файлов сразу. Файлы больше 5 МБ не принимаются.

Пример:
```
>>> Что не так с этим кодом? @::/home/user/main.py::
```

**`/file_chunk`** — режим обработки файла по кускам. Удобно, если нужно попросить модель разобрать большой файл по частям.

Варианты:
```
/file_chunk                  # по одному абзацу
/file_chunk paragraph=3      # по 3 абзаца
/file_chunk len=500          # по 500 символов
/file_chunk len=500 -y       # то же, но без паузы между кусками
```

После ввода команды программа спросит путь к файлу и что нужно делать с каждым куском. Дальше на каждом шаге нажимаешь Enter или пишешь `\q` чтобы прервать.

## Что реализовано

1. Основной цикл чата
2. Обрезка контекста по количеству сообщений и символам
3. Загрузка конфига из файла и переменных окружения, валидация
4. Ctrl+C во время запроса отменяет его и возвращает в чат
5. Вставка файлов через `@::путь::`
6. Режим `/file_chunk`
7. Команда `\q`
8. Команда `/reset`
